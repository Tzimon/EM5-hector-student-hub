# Function 2 – Specification: Projects & Calendar (HTML Mockup)

---

## 1. Calendar Behavior

### 1.1 Module & Project Structure

- **10 modules** in total: **5 engineer modules** and **5 management modules**
  → this results in **5 engineer projects** and **5 management projects** (one project per module).
  - Original note: "10 modules with 5 engineer modules and 5 management modules => 5 engineer project and 5 management module"
- Each module lasts **2 weeks**.
- The project can take place in the **first or second week** of a module and lasts **a maximum of 3–5 days**.

### 1.2 Default View & Filtering

- Default to the **month containing the sample "today"**.
- Allow **filtering by course** and **by event type**.

### 1.3 Display of Entries

- Show the **company name** alongside project-related entries.
- Use **distinct labels and colors** for project periods and course sessions.

### 1.4 Interactions

- Selecting a **project period** opens **project details** (see section 2).
- Selecting a **course session** opens **course details**.

### 1.5 Course Details

- Course details show:
  - course name
  - lecturer
  - schedule
  - description
  - linked company projects
- Selecting a linked project **replaces the panel content** (with the project detail view) and provides a **Back** control.

---

## 2. Project Overview (Project Detail View)

Each project detail view shows:

- **Project title**
- **Association name** (e.g. NGOs like WHO, or companies like BMW, …)
- **Associated course**
- **Lecturer**
- **Brief**
- **Expected outcome**
- **Start date** and **end date**
- **Team name** and **members**
- **The current student's role**
